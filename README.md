## Task 0 - Responsive Typography

In this task I created headings and paragraphs and made the text responsive. I used media queries to change the font size for mobile, tablet and desktop screens.

## Task 1 - Responsive Layout

In this task I created three boxes. I used CSS media queries to change their position depending on the screen size. On desktop there are three boxes in one row, on tablet there are two boxes in a row, and on mobile the boxes are displayed vertically.

## Task 2 - Bootstrap Grid

In this task I used the Bootstrap grid system. I created three responsive columns using col-12, col-md-6 and col-lg-4. On mobile they are displayed one under another, on tablet there are two columns in a row, and on desktop there are three columns in one row.
